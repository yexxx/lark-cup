# 超级码力 · 1024 程序员节 · Relay 创造营

以像素冒险世界呈现的内源社区 AI 创作活动。让灵感起飞，让码力集结。

可自行部署的单赛道 AI 创作比赛：作品展示、报名、直接发布、每日投票、排行榜、管理后台。前端 React + TypeScript，后端 Fastify，生产环境 PostgreSQL + Redis + Nginx。

固定提示词：

> 创建一个 HTML，内容是用 SVG 绘制一只飞行中唱歌的百灵鸟的 2D 动画。

提交的是 **HTML 文件**，百灵鸟使用内嵌 SVG 绘制。首页像素场景使用独立图片素材；示例作品的主体是 SVG，封面从对应 SVG 生成，不用位图充当作品。

## 本地运行

需要 Node.js 24。无 Docker 时使用持久化 PGlite（嵌入式 PostgreSQL）和内存缓存，不会自动混入演示数据。

```sh
npm ci
npm run seed    # 可选：显式初始化 8 个 HTML + SVG 示例及示例票数
npm run install:browser # 安装本地截图用 Chromium
npm run dev
```

打开 http://localhost:5173。API 为 3001，隔离作品预览为 3002。本地数据在 `.local/`，不要让多个服务进程同时打开同一 PGlite 数据目录。需要重新执行迁移或 seed 时先停止开发服务。

```sh
npm run build      # TypeScript 检查及前端生产构建
npm test           # 独立临时数据库，串行运行
npm run test:guide # 隔离前端服务及接口数据，检查操作引导与桌面／手机布局
npm run test:load  # 只允许 localhost，依次 1 / 5 / 10 并发，每 worker 4 次请求
```

## 注册与登录

参赛者使用用户名、显示姓名和密码自助注册，注册后自动登录。用户名为 3～32 位英文字母、数字、下划线或短横线，统一小写判重；显示姓名允许重复。密码为 8～128 个字符，支持中文、空格和 Unicode，采用独立盐的 scrypt 哈希存储。

每个设备持有独立的 HttpOnly 会话 Cookie。会话保存在数据库中，服务重启后继续有效；默认最长 7 天、闲置 24 小时过期。退出撤销当前设备会话，修改密码、管理员重置密码或停用账号会撤销全部会话。同浏览器标签页共享当前账号并同步状态，多设备和不同浏览器可同时登录。

管理员通过服务器交互命令创建，密码输入会隐藏；普通注册统一获得参赛者权限：

```sh
npm run auth:create-admin
npm run auth:reset-password
```

本地使用 PGlite 时，执行管理命令前先停止开发服务；可通过 `LOCAL_DATABASE_DIR` 指定独立数据库目录（默认 `.local/postgres`）。生产环境在 API 容器中执行命令，见 [部署手册](docs/deployment.md)。忘记密码时联系赛事管理员重置。

后端通过 `AuthAdapter` 读取稳定的用户 ID 与角色。`auth_identities` 存储提供方、可信 subject 与用户 ID 的映射；`createSessionStore` 提供会话读取、建立和退出能力。后续企业 SSO 校验身份后，可复用用户归属和会话机制。当前提供用户名密码认证。

新增认证迁移保留既有业务数据；旧演示用户保持原数据归属。新比赛使用独立空数据库与上传目录，参赛者注册后生成新用户 ID。

## 已实现流程

- 页面分步操作引导：通过导航、页脚或投稿／我的作品／登录弹窗的“操作引导”手动开启，覆盖参与活动、注册登录、投稿、作品管理、浏览、投票与榜单。支持上一步、下一步、跳过及重看，按当前赛程、票额和作品状态讲解，手机使用底部说明卡。
- 固定提示词报名，支持选择文件或粘贴 HTML 源码、HTML 文件、截图和封面图片；草稿、直接发布、编辑和撤回。作品介绍、模型和封面可选填，提供 HTML 后自动生成封面。
- 作品搜索、分页、精选／最新／高票排序，隔离域名交互预览，复制作品链接。
- 默认每日 10 票，同一作品每天 1 票，北京时间零点换日。服务端事务处理幂等、唯一性和额度并发扣减。
- 榜单同票同名次，缓存 15 秒；列表缓存 10 秒。投票后当前卡片立即显示成功，其他列表在缓存更新后展示新票数。
- 管理后台配置赛事、赛程和次日额度，推荐和下架作品，启用停用用户，查看和作废投票，审计日志及 CSV 导出。
- HTML 最大 5MB；封面最大 2MB，JPEG/PNG/WebP。图片会校验真实格式并转为 WebP。HTML 检查实际 SVG 节点，拒绝 SVG 内嵌位图或 HTML；赛事管理员可核实违规内容并下架作品。
- 自动封面使用独立 Chromium 服务离线渲染 HTML；生成期间或失败时使用占位封面，恢复后补图。交互预览使用独立 origin、iframe sandbox 和 CSP，外部网络、父页面访问、弹窗及顶层导航受限。

部署、域名、HTTPS、资源上限、备份恢复和回滚见 [部署手册](docs/deployment.md)。接口见 [API 文档](docs/api.md)。

## 目录

```text
src/              前端页面、认证适配器、请求并发队列
server/           API、投票事务、账号与会话、迁移、SVG 示例源码
tests/            业务、上传、隔离、限流测试
deploy/           Nginx HTTP / HTTPS 与 Compose 覆盖配置
docs/             部署、接口、设计与验证说明
```

`001_initial.sql` 保留最初数据模型，`002_single_track.sql` 迁移为单赛道并合并历史额度。内部 `classic` 只是历史数据库键，界面不显示赛道，也不能提交第二种赛道。

## 活动品牌与界面

首页使用连续的像素天空、彩虹城堡与可交互百灵鸟。手机将活动信息置于清晰的浅色面板，场景贯穿整个首屏。作品展区、榜单、投稿、我的作品与后台共用硬边框、金币黄按钮与深蓝文字。

活动名称、口号、简介与赛程由后台配置。`003_super_code_brand.sql` 逐字段更新旧默认品牌值，保留自定义内容、奖项与赛程；1024 为主题标识。新增迁移由服务启动流程自动执行。
