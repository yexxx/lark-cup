# 设计依据与决策

最终范围：单赛道、固定提示词、HTML 内嵌 SVG 作品、每日投票和后台审核。用户明确要求不复制原参考站，并授权自行决定设计。

## 过程

1. 检查了原参考站和当前本地页面的桌面截图、作品浏览、登录占位与投票入口。
2. 用 Product Design ideate 串行生成三种视觉方向：森林展廊、自然手记、开阔草地。每种具有不同的布局和信息优先级。
3. 选择森林展廊：自然风景 + 统一提示词导入，下方侧边浏览方式和三列作品。它比双列手记更方便浏览作品，比不规则大卡布局更便于公平对比和展示余票。
4. 实现后按同一桌面尺寸比较设计稿与页面，并检查手机布局、表单、详情预览、榜单和后台。

## 具体决策

- 不再使用参考站的像素横幅、黄色滚动条、硬边按钮、赛道筛选和同款页面框架。
- 色彩以森林绿、暖白和浅苔绿为主，陶土色用于主要提交按钮；仅轻微边线与阴影。
- 标题使用系统宋体／衬线字体，控件使用系统无衬线字体，无外部字体请求。
- 首屏展示统一提示词，作品列表紧接其后。直接点击“发现作品”可跳过首页导入，进入纯浏览页面。
- 桌面侧栏显示排序与剩余票数；手机将它们变为顶部横向导航与余票条。
- 作品封面为静态预览，避免同时执行多个动画。进入详情后才启动一个隔离预览。
- 隐藏作者身份，未采用生成稿中的头像与作者标签；票数全部来自数据库，不复用设计稿的示意数字。
- 首页背景为原创生成图片；示例作品主体和动画是真实 SVG 路径。封面由同一 SVG 源码生成。
